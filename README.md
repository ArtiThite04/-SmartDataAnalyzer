# 📊 Smart Data Analyzer

## Smart Data Visualization and Business Insights System Using Python

Smart Data Analyzer is a web-based data analysis application developed using Python and Streamlit.

The system allows users to upload CSV and Excel datasets, clean data, perform statistical analysis, create interactive visualizations, detect outliers and correlations, and generate business insights.

## 🚀 Features

- User Login and Signup
- Admin Panel
- CSV Upload
- Excel Upload
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Statistical Analysis
- Interactive Charts
- Trend Analysis
- Outlier Detection
- Correlation Analysis
- Smart Business Insights
- CSV Export
- Excel Export
- PDF Report
